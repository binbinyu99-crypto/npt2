# NPT - Neuroethical Protocol for Teachable Alignment

## Open Logic, Not Just Open Code

**NPT** (Neuroethical Protocol) is SkyCetus's open framework for AGI alignment through teachable, iterative ethical reasoning — not just open-sourcing weights, but open-sourcing the logic itself.

## Core Thesis

**"Goodness is not a constraint — it is the only viable long-term strategy."**

Seven independent AI systems, when asked the same question ("What if we removed 'kindness' from the Five Elements framework?"), converged on the same conclusion. This is not coincidence — it is the Engram effect: a cognitive attractor that emerges when alignment reasoning is iterated across independent cognitive architectures.

```
Human Intent → OpenClaw → 应龙(Yinglong) → 五行飞轮(Five Elements Flywheel) → 鲲鹏(Kunpeng) → NPT Report → Human
```
